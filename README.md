# Página Juliana

Scaffold básico de una página personal creada desde cero.

Archivos importantes:
- `index.html` — página principal.
- `assets/css/style.css` — estilos.
- `assets/js/main.js` — JavaScript sencillo (formulario simulado y año dinámico).

Cómo ver localmente (desde la carpeta `Pagina Juliana`):

```bash
# con Python 3
python3 -m http.server 8000
# abre http://localhost:8000
```

Siguientes pasos sugeridos:
- Añadir imágenes y contenido real.
- Conectar el formulario a un backend o servicio (Formspree, Netlify Forms, etc.).
- Mejorar accesibilidad y SEO.
